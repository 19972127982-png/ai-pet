性格自适应系统（核心创新）

设计理念

传统聊天机器人的「人设」是静态的——从第一天到第一百天，性格不会有任何变化。小橘的自适应系统打破了这一限制：

你怎么对它，它就会变成什么样。
跟它开玩笑 → 它学会毒舌；每天陪它聊 → 它变得粘人；需要安慰 → 它越来越温柔。

三维度性格模型

性格用三个独立维度描述，每个维度在 [-1, +1] 范围内连续变化，不是离散档位：

Energy 活力轴
安静内敛
活泼好动
Attachment 依恋轴
独立高冷
粘人撒娇
Sharpness 锋利轴
温柔体贴
毒舌傲娇

初始状态：所有维度从 0（中性）开始
变化幅度：每次对话 ±0.01 ~ ±0.03（渐进式，不会突变）
感知阈值：约 10-20 次对话后开始感受到明显风格变化
参数边界：严格 clamp 在 [-1, +1]，不会溢出

演化触发规则

你的行为性格变化结果
话多、热情、感叹号多energy ↑猫咪被带动变活泼
话少、安静、深夜聊天energy ↓猫咪学会安静陪伴
频繁来聊、表达想念attachment ↑猫咪变得更粘人
回复简短、长时间不来attachment ↓猫咪学会独立
幽默吐槽、开玩笑sharpness ↑猫咪学会怼人
伤心脆弱、需要安慰sharpness ↓猫咪变得温柔

性格如何体现在对话中

同一个问题「今天做了什么？」，不同性格的小橘回复截然不同：

渐进式演化的体验设计

为什么选择极小幅度的渐变而非突变？

像养真实宠物一样：你不会在某一天突然发现猫的性格变了，而是在某个瞬间回想起"它以前不是这样的"——这种渐进感才是养成的核心乐趣。
设计决策原因
每次变化 ±0.01~0.03用户无法感知单次变化，但累积后差异显著
分析由 LLM 执行规则引擎无法理解语义；LLM 能精确判断"这句话是开玩笑还是真生气"
异步执行，不阻塞 UI分析请求在回复显示后静默运行，用户无感知
三维度独立变化组合出 8 种以上明显不同的性格类型，给每个用户独特体验

性格演化执行流程

1
构建动态 System Prompt
读取当前性格参数 + 成长阶段 + 记忆摘要，拼接为完整人设指令
2
LLM 流式对话
猫咪依据动态 Prompt 生成回复，性格实时体现在用词和语气中
3
前端逐 token 渲染
SSE 流式接收，实时更新消息气泡，打字机效果
4
性格演化分析（异步）
独立 LLM 调用分析本轮对话，返回 {"energy": 0.02, "attachment": 0.01, "sharpness": -0.01}
5
参数更新 & 持久化
Clamp 到 [-1,1] 范围后写入 localStorage，下次对话生效
6
记忆摘要更新（每 10 次对话）
LLM 从历史对话中提取用户关键信息（名字、职业、喜好、近期事件）

动态 Prompt 生成示例

// personality = { energy: 0.6, attachment: 0.3, sharpness: -0.4 } // 生成的 System Prompt: 你是一只名叫"小橘"的猫咪电子宠物。 【成长阶段：熟悉】 你们已经比较熟了，你开始展现真实的自己。 【你的性格】 - 你超级活泼好动！话很多，经常蹦蹦跳跳 - 你喜欢粘着主人，会主动找话题聊 - 你说话温和友好，偶尔调皮一下 【记忆】 - 主人叫小明，是大学生 - 最近在准备期末考试 - 喜欢深夜来聊天

性格分析 Prompt

每次对话结束后，发送独立请求给 LLM 进行语义分析：

// 输入: 当前参数: energy=0.6, attachment=0.3, sharpness=-0.4 用户说: "哈哈哈你太搞笑了！" 猫咪说: "那当然！有本喵在还能无聊吗" // LLM 返回 (严格 JSON): {"energy": 0.02, "attachment": 0.01, "sharpness": 0.01}
