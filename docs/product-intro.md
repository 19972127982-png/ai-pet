## 一、产品简介

「小橘」是一款基于大语言模型驱动的 AI 电子宠物。不同于传统电子宠物的固定脚本回复，小橘拥有**自适应性格演化系统**——它的性格、说话方式会根据与用户的互动逐渐变化，形成独一无二的陪伴关系。

### 核心卖点

| 特性 | 说明 |
|------|------|
| 性格自适应 | 三维度性格参数随对话自动演化 |
| 对话记忆 | 记住用户说过的话，能主动引用 |
| 情感感知 | 识别用户情绪并做出对应回应 |
| 成长体系 | 初识→熟悉→亲密→挚友四阶段成长 |
| 零门槛使用 | 打开网页即用，无需安装 |

## 三、核心功能：性格自适应系统

### 3.1 设计理念

传统聊天机器人的「人设」是静态的——从第一天到第一百天，它的性格不会有任何变化。小橘的性格自适应系统打破了这一限制：

> **你怎么对它，它就会变成什么样。**

如果你总是跟它开玩笑，它会慢慢学会毒舌；如果你每天都来陪它聊天，它会变得更粘人；如果你心情不好需要安慰，它会变得越来越温柔。

### 3.2 三维度性格模型

性格用三个独立维度描述，每个维度在 [-1, +1] 范围内连续变化：

```
          -1                0                +1
           │                │                │
  energy   ├── 安静内敛 ────┼──── 活泼好动 ──┤
           │                │                │
attachment ├── 独立高冷 ────┼──── 粘人撒娇 ──┤
           │                │                │
 sharpness ├── 温柔体贴 ────┼──── 毒舌傲娇 ──┤
           │                │                │
```

**初始状态**: 所有维度从 0（中性）开始  
**变化幅度**: 每次对话 ±0.01 ~ ±0.03（渐进式变化）  
**感知阈值**: 约 10-20 次对话后开始感受到明显风格变化

### 3.3 演化触发规则

| 用户行为 | 性格变化 | 说明 |
|----------|----------|------|
| 话多、热情、用感叹号 | energy ↑ | 猫咪被带动变活泼 |
| 话少、安静、深夜聊天 | energy ↓ | 猫咪学会安静陪伴 |
| 频繁来聊、表达想念 | attachment ↑ | 猫咪变得更粘人 |
| 回复简短、长时间不来 | attachment ↓ | 猫咪学会独立 |
| 幽默吐槽、开玩笑 | sharpness ↑ | 猫咪学会怼人 |
| 伤心脆弱、需要安慰 | sharpness ↓ | 猫咪变得温柔 |

### 3.4 性格如何体现在对话中

以同一个问题「今天做了什么？」为例，不同性格的小橘回复截然不同：

**安静 + 独立 + 温柔 的小橘：**
> 嗯...今天就在窝里待着。你呢？

**活泼 + 粘人 + 毒舌 的小橘：**
> 等你啊！！你怎么才来！！我都无聊死了喵！（气鼓鼓）你是不是又在摸鱼没理我！

### 4.2 性格演化技术实现

#### 流程图

```
用户发送消息
      │
      ▼
┌─────────────────┐
│ 1. 构建动态 Prompt│  ← 根据当前性格参数生成 System Prompt
│    (prompt-builder)│
└────────┬────────┘
         ▼
┌─────────────────┐
│ 2. LLM 流式对话  │  ← 猫咪回复（受性格影响）
│    (chat-stream) │
└────────┬────────┘
         ▼
┌─────────────────┐
│ 3. 显示回复      │  ← 前端逐 token 渲染
└────────┬────────┘
         ▼ (异步，不阻塞 UI)
┌─────────────────┐
│ 4. 性格演化分析  │  ← 独立 LLM 调用，返回微调 JSON
│    (personality) │
└────────┬────────┘
         ▼
┌─────────────────┐
│ 5. 更新参数      │  ← clamp 后写入 localStorage
└────────┬────────┘
         ▼ (每 10 次对话)
┌─────────────────┐
│ 6. 记忆摘要更新  │  ← LLM 提取用户关键信息
│    (memory)      │
└─────────────────┘
```

#### 动态 Prompt 生成示例

```javascript
// 性格参数 → 人设描述的映射
personality = { energy: 0.6, attachment: 0.3, sharpness: -0.4 }

// 生成的 System Prompt:
`你是一只名叫"小橘"的猫咪电子宠物。

【成长阶段：熟悉】
你们已经比较熟了，你开始展现真实的自己。

【你的性格】
- 你超级活泼好动！话很多，经常蹦蹦跳跳
- 你喜欢粘着主人，会主动找话题聊
- 你说话温和友好，偶尔调皮一下

【记忆】
- 主人叫小明，是大学生
- 最近在准备期末考试
- 喜欢深夜来聊天

...`
```

#### 性格分析 Prompt

每次对话后，发送一个独立请求给 LLM 进行分析：

```
分析对话，返回性格微调值（JSON）：
当前: energy=0.6, attachment=0.3, sharpness=-0.4
用户说: "哈哈哈你太搞笑了！"
猫咪说: "那当然！有本喵在还能无聊吗"
→ {"energy": 0.02, "attachment": 0.01, "sharpness": 0.01}
```

### 4.3 记忆系统

每 10 次对话自动触发记忆摘要更新：

```
输入: 最近 40 条对话历史
   ↓ LLM 提取
输出:
  - 主人叫小明，是一个大学生
  - 最近在准备期末考试，压力比较大
  - 喜欢打游戏和看动漫
  - 经常深夜来聊天
```

记忆摘要注入到 System Prompt 的 `【记忆】` 部分，使猫咪能引用历史话题。

### 4.5 技术栈总览

| 层面 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | 原生 HTML/CSS/JS (ES Modules) | 零依赖，无构建步骤 |

| 存储 | localStorage | 纯客户端，隐私友好 |
| 部署 | Netlify (免费) | 推送即部署，全球 CDN |
